# Lecture 8 — VaR Backtesting

This lecture develops the market-risk material from Lecture 7 by evaluating one-day VaR forecasts out of sample.

The notebook covers:

- Rolling Historical VaR
- Rolling Normal VaR
- EWMA + Normal VaR
- GARCH + Normal VaR
- VaR breaches
- Unconditional coverage backtesting
- Independence of breaches
- Optional model extensions
